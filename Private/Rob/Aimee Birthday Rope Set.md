- **8 Sep 2026:** the Rope Locker 220m hemp reel arrived. Rob cut 3m test lengths and put them to soak. Test dye baths today: 50/50 and 75/25 turquoise/cerulean, 1L each, one 3m hank (~80-90g) per bath.

If both still dry green, buy Mixing Blue MX-R.
