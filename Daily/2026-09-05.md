## Work & Projects

### Plex / Proxmox (10:38)
Rob reported Plex dead since last night, CPU pegged at 100%, service restart / stop / CT reboot all hanging. Root cause: at 21:59 on 04 Sep the GTX 1080 Ti threw NVRM Xid 62 + Xid 31 (MMU fault) + Xid 65 against the Plex Transcoder mid-transcode. A transcoder thread segfaulted in libnvcuvid, and the main thread got stuck spinning in `uvm_spin_loop` in the nvidia_uvm kernel module: unkillable (SIGKILL ignored), burning a full core for 14.5h. Plex Media Server itself was a zombie. Because the stuck process could never exit, CT 100 could never finish stopping, so all of Rob's restart attempts (vzreboot task, vzstop, my `pct stop --skiplock`) hung on it. `nvidia-smi --gpu-reset` refused (primary GPU). Only fix: full host reboot. Verified DKMS had the nvidia module built for the running kernel (7.0.14-14-pve) and `nvidia-lxc-devices.service` enabled, then issued `shutdown -r` on the host. All guests have `onboot: 1` since the 2026-08-27 audit.

Watch item: Xid 62 can indicate GPU hardware instability (heat, power, or a dying card). One-off for now, but if transcodes start killing the GPU again, suspect the 1080 Ti itself. Logged in Infrastructure.md.
