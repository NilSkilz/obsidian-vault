### Tethered: blog empty for signed-in users (16:34)
- Rob applied the single 404-200 Amplify rewrite (08:50); prerendered blog HTML now serves correctly, sitemap and list page carry all 11 posts.
- But he saw the posts flash then vanish on both Mac and phone. Reproduced in headless Chrome: as a guest the GraphQL query returns all posts, so the API is fine. Root cause: both public blog pages hardcoded `authMode: "identityPool"`, and a signed-in user gets the authenticated IAM role which `allow.guest()` doesn't cover, so the query comes back empty. Rob is signed in on both devices; fresh browsers (and crawlers) were fine. The exact gotcha was already documented in `AmplifyAdapter.ts` (`getPublicReadClient`).
- Fix: exported `getPublicReadClient()` and used it in `BlogListPage`/`BlogPostPage`. Typecheck, 487 tests, build all green. Pushed to develop (`d84af13`).
