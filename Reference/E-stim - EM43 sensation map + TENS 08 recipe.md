# E-stim quick reference — Boots EM43 (sensation map + TENS 08 recipe)

Kit: Boots EM43 dual-channel TENS/EMS, biphasic square wave, **1–150 Hz / 50–450 µs**, intensity **0–50 per channel**. See [[reference_estim_kit]] for the kit, connector gap, and safety. Cardinal rule below is non-negotiable.

## The three dials (don't merge them)

- **Programme** = the pulse pattern/character. Fixed per programme. Only 6 are user-tunable: **TENS 08/09/10, EMS 28/29/30**. TENS 08 is the one where you set *both* Hz and µs by hand.
- **Frequency (Hz)** = the *rhythm/feel* of the sensation. What changes it from a slow roll to a locked clench.
- **Pulse width (µs)** = the *depth/body* of each pulse. How much tissue it recruits, how "thin and sharp" vs "deep and full" it feels. Higher µs also feels stronger at the same intensity.
- **Intensity (0–50)** = master "how hard," independent per channel. Works on any programme. Always your last knob up, first knob down.

## Frequency → sensation

- **1–10 Hz** — slow, distinct throbs/taps. You feel each pulse land separately. Rolling, teasing, thuddy.
- **10–20 Hz** — flutter/buzz starting to blur together. Massage-y, warm.
- **20–35 Hz** — smooth vibration, a strong hum. Pulses fully fused.
- **35–50 Hz** — twitch/kick territory, muscle starts to pull.
- **45–70 Hz** — **locked, sustained clench** — the "gripping" sensation. Muscle held, not tapped.
- **70–120+ Hz** — fine, sharp, buzzy/tingly, more surface bite, less deep grip. Can numb over time.

## Pulse width → sensation

- **50–150 µs** — thin, sharp, surface-y. Prickle/sting. Sits shallow.
- **150–300 µs** — the useful middle. Rounded, full, "meaty." Most controllable.
- **300–450 µs** — deep, broad, heavy. Recruits more, feels much stronger, can tip into a dull ache/cramp fast. Bring intensity down when you widen the pulse.

## Recipes (freq × width, then bring intensity up slow)

- **Teasing throb** — 4–8 Hz, 200–300 µs. Slow deep taps.
- **Warm massage** — 15–20 Hz, 200 µs. Blurry buzz, relaxing.
- **Deep grip / clench** — 50–60 Hz, 300–400 µs. The classic "held" squeeze.
- **Sharp bite** — 90–120 Hz, 80–120 µs. Fast, shallow, stingy.
- **Rolling build** — start 5 Hz / 250 µs, walk frequency up toward 50 Hz over a scene to go from taps to grip without touching intensity.

## TENS 08 recipe (the tunable one)

TENS 08 is the free-hand programme: you dial **both** frequency (Hz) and pulse width (µs) yourself, plus intensity per channel.

**Default starting point:**
1. Zero the intensity dial on the channel before connecting anything.
2. Set **frequency ~50–60 Hz** for a sustained grip, or drop to ~5–10 Hz for distinct throbs.
3. Set **pulse width ~250 µs** (round and full; go narrower for sharper, wider for deeper).
4. Connect, then bring **intensity up from 1–2 slowly** to the level you want.
5. To change the *feel* mid-scene, move Hz first; only touch µs/intensity if you want more body/strength.
6. Zero the dial again before disconnecting or repositioning.

## Cardinal safety rule

Keep the **entire current path below the waist / local** — both contacts same side or same local area. **Never cross the torso or heart** (no hand-to-hand, no left-vs-right chest). Leaflet hard-bans pads on the front of the chest/pecs. Stainless not bare copper. Bigger/wetter contact = smoother. No pacemaker/heart condition/epilepsy/pregnancy near it.
