# Tethered UI sweep, 16 Nov 2026

Read-only sweep of dashboard forms, modals and the safety timer, run after the number-field bugs. Findings came from a code read, not a browser session.

## Fixed on develop (`d012acf`, `72ff9a7`)
- Paused tasks vanished from the Manage page, so Resume was unreachable. Now listed after active tasks.
- Free-tier "Subscribe Now" pointed at `/timer/settings` (dead route). Now `/dashboard/settings`.
- Safety timer: double tap on Start could create two scenes; a failed start or a failed "I'm okay!" was silent; pasted `+44...` / `0044...` numbers were saved with +44 twice; terms checkbox did not reflect its state.
- Rewards: clearing max claims or cooldown on edit did not save; negatives accepted.
- Plurals (1 day, 1 task, 1 activity).
- Reward cost +/- steps by 1.

## Open (not fixed, need a decision or more care)
1. **Notification failure reported as action failure.** Claim reward, fulfil/deny, end relationship, task completion: the action succeeds, the partner notification throws, the user sees "failed" and can retry (double claim possible). `ClaimRewardModal.tsx:47`, `ManagePage.tsx:529,557`, `PartnersPage.tsx:87`, `SubDashboardPage.tsx:538`.
2. **Edit can't clear a task's due date or a linked activity** (task, reward, punishment modals): `undefined` is dropped from the update, needs `null`.
3. **Due dates use the UTC date as "today"** (`CreateTaskModal.tsx:138,248,618`). Wrong for US evenings and AU/NZ mornings.
4. **Invite link lost if the clipboard write fails** (iOS Safari), `PartnersPage.tsx:60`. No fallback showing the link.
5. **Safe-word autosave** fails silently and can create duplicate UserInfo rows, `SafeWordsPage.tsx:44`.
6. **Sign-up shows "name already taken"** for any display-name check failure, including over 30 chars or a network blip. `AuthModal.tsx:111`.
7. **Counted tasks:** single in-flight slot shared across tasks (tapping +1 on two tasks quickly can error), stale meter if the page is left open overnight, +1 still shown if the Dom lowers the target below the count.
8. **Completed time on recurring tasks** uses `updatedAt` (last edit), so "done 5 min ago" can read "12d ago". `SubDashboardPage.tsx:180`.
9. **Home "Tasks Due Today"** ignores completions and counted progress. `HomePage.tsx:108`.
10. **Notification taps** always open the partner profile, not the approval queue. `NotificationBell.tsx:116`.
11. **Settings page** can spin forever on a fetch failure; subscribe/portal buttons fail silently. `SettingsPage.tsx:35`.
12. **Template pack partial failure** leaves some tasks created; "Add All" again duplicates them.
13. Blank activity chip when editing a linked activity; "Saved N ratings!" toast shown even when every save failed.

## Not covered
ScenePlanPage, PartnerProfilePage, InfoPage, AftercarePage, ComparePage and most shared modals were only grepped. `TasksPage`, `RewardsPage`, `PunishmentsPage` are unrouted dead code.
