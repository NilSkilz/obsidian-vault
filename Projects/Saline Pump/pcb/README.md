# Saline Pump — KiCad schematic (v1)

`saline_pump.kicad_sch` is a self-contained KiCad 7/8 schematic. Generated by
`gen_schematic.py` (edit the Python + re-run to regenerate, don't hand-edit the
`.kicad_sch` unless you're doing final layout tidy).

## How to import

1. KiCad → **New Project** (call it `saline_pump`), then in the project folder
   **replace** the empty `saline_pump.kicad_sch` with this file (or File → Open
   the `.kicad_sch` directly).
2. Open in the Schematic Editor. Every part is drawn as a labelled box; all
   wiring is by **net label** (matching names = same net), so it's electrically
   complete even though it's laid out on a grid, not prettified.
3. **Tools → Annotate** (fills any `?` refs), then **Tools → Assign Footprints**,
   then **Update PCB from Schematic** to start the board.
4. Symbols are generic placeholders (a box + named pins). For the real board,
   swap each for the proper KiCad library symbol/footprint during footprint
   assignment, or keep the boxes and just assign footprints. The **netlist is
   the deliverable** here, not pretty symbols.

Not using KiCad? EasyEDA (JLCPCB's tool) can't read `.kicad_sch` directly, but
the pin/net table below is everything you need to redraw it in any tool.

## Locked pin map (ESP32 DevKitC 30-pin, WROOM-32)

Proposed v1 — confirm on the perfboard proto before fabbing. Strapping pins
(0, 2, 12, 15) and the serial pins (1, 3) are deliberately left clear. No ADC
used (encoders + HX711 are digital), so ADC2/WiFi conflict is a non-issue.

| Signal | GPIO | Notes |
|---|---|---|
| PUMP_L gate | 25 | → 150Ω → Q1 gate, 10k pulldown to GND |
| PUMP_R gate | 26 | → 150Ω → Q2 gate, 10k pulldown |
| ENC_L A / B / SW | 32 / 33 / 27 | internal pullups in firmware |
| ENC_R A / B / SW | 14 / 13 / 22 | internal pullups |
| TFT_MOSI (SDA) | 23 | shared both displays |
| TFT_SCK (SCL) | 18 | shared |
| TFT_DC | 16 | shared |
| TFT_RST | 17 | shared |
| TFT_CS_L | 5 | left display chip-select |
| TFT_CS_R | 4 | right display chip-select |
| HX711_SCK | 21 | shared clock, both bases |
| HX711_DT_L | 34 | input-only pin, fine (HX711 drives it) |
| HX711_DT_R | 35 | input-only pin |
| ESTOP_SENSE | 19 | optional: 100k/33k divider off +12V_SW (~3.0V) |

Backlight (BLK) on both displays tied to +3V3 (no GPIO). Saves a pin vs PWM
dimming; add a GPIO later if you want brightness control.

## Circuit blocks

- **Power:** barrel jack +12V → E-stop (NC) in the pump high-side rail → +12V_SW
  to the pumps only. Buck (MP1584) runs off raw +12V, so the ESP32 stays alive
  when the e-stop kills the pumps (UI still shows STOPPED). +3V3 comes from the
  ESP32's onboard regulator and feeds the displays + HX711 bases (3.3V so DT
  lines are ESP32-safe — do **not** power HX711 at 5V).
- **Pump drivers ×2:** IRLZ44N low-side, 150Ω gate series R, 10k gate pulldown
  (holds pumps off at boot), 1N5822 flyback across each motor.
- **Displays ×2:** GC9A01, shared SPI bus, unique CS each.
- **HX711 bases ×2:** 4-pole TRRS jacks, shared SCK, separate DT.
- **Decoupling:** 470µF + 100nF on +12V, 100µF + 100nF on +5V at the ESP32.

Bulk cap + flyback placement matters — motor inrush on a WiFi board is exactly
what browns out a WROOM mid-scene.
